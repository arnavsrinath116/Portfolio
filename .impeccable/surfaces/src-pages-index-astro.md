# Home (first sheet): header, hero, footer

Mode: Experience. Scope: header, hero and footer only; no projects yet (a dashed "in drafting" band stands in honestly). Audience and constraints: see PRODUCT.md.

## Direction contract

THESIS: The home page is sheet A-000 of a drawing set being drafted live: scrolling measures and annotates the owner's name like a technical drawing, and a liquid-mercury ferrofluid cursor is the one living, organic thing on a precise sheet. Refuses the default portfolio hero (centered name, subtitle, two buttons, scroll arrow).

OWN-WORLD: Slate #14171A sheet, sand #E6DCC8 linework and lettering, orange #FF6B2C reserved for dimensions, leaders and live state. Line weights carry meaning (hairline grid, 1px objects, dashed = not yet built). Archivo at expanded width for lettering, Geist Mono only for measurements and sheet data. Title block, zone-marked sheet border, + registration marks. Mercury is the only material with depth.

STORY: In one second the visitor reads ARNAV SRINATH'S / PORTFOLIO and PRODUCT · UX · HMI; scrolling proves craft by dimensioning the name with live measurements; the footer drafts the name again and offers contact.

FIRST VIEWPORT: Fixed sheet border with zone ticks; header with an isometric AS cube left and [ MENU ] right; two-line stacked heading left-weighted, line two offset right, tags beneath; live drafting grid behind reacting to the cursor; title block bottom-right. Primary action: MENU / contact in footer.

FORM: Owner-pinned direction (blueprint line art, dark slate, sand lines, orange accent, plotter-sweep intro, ferrofluid cursor, fluid-flood menu); the owner pinned the full composition in an interview, so the concept roll was waived (it is available on this machine). seed: none (waived, owner-pinned)
